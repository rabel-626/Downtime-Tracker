# Downtime Tracker — Data & Privacy

## Browser Use

The tool is designed as a browser-based application. Local browser storage may be used for autosave or recovery depending on the current build.

## Exported Files

Saved JSON and report exports are files controlled by the user after download.

## Recommended Practice

- Save studies to an approved project or study folder.
- Avoid entering sensitive personal information in free-text notes.
- Retain the tool version with important study records when reproducibility matters.
- Verify site-specific information-handling requirements before sharing exported files.
