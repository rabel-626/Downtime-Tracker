# Downtime Tracker — Quick Start

## Purpose

Use the Downtime Tracker to record production downtime events, classify them by reason code, retain study context, and review the resulting downtime profile.

## Typical Workflow

1. Open the tool and complete **Study Information**.
2. Confirm or load the downtime-code setup.
3. Choose the desired **Entry Mode**.
4. Start the observation window.
5. Record downtime events as they occur.
6. Add notes when an event needs context.
7. Review **Data Quality Checks** and the event log.
8. Review summary statistics and the included-cause Pareto.
9. Save the study JSON and export any required report files.

## Before Starting

Confirm the production line or machine, date, shift, product/job, observer, and the reason-code structure that should be used for the study.

> Preserve the saved study JSON when traceability matters. It is the best source for later re-analysis and multi-study aggregation.
