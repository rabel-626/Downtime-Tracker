# Downtime Tracker — Methodology Reference

## Observed Time

Observed time is the study window over which production and downtime are being evaluated.

## Downtime Events

A downtime event represents a defined interruption with a duration and reason classification. Reason-code quality directly affects Pareto quality.

## Pareto Interpretation

The Pareto should be used to identify where observed downtime is concentrated. High total duration does not automatically establish root cause; it identifies a priority for investigation.

## Included and Excluded Causes

If the tool allows causes to be excluded from a particular analysis, document why they were excluded. Exclusion changes the analytical view and should not be used to hide valid process loss.

## Engineering Review

Use event notes, production context, and source observations when deciding whether a recurring loss warrants corrective action.
