Event Log

CSV Ready
The Event Log is the main downtime record. Timer mode captures timestamps automatically. All event views stay compact with only Duration and Details; open Details to review or edit category, cause/reason code, start/stop timestamps, and notes.
  • Study timer: Press Start Study when observation begins and Stop Study when observation pauses or ends. You can start and stop the study multiple times; each run is added to the total logged study time.
  • Study timer calculations: Hidden or excluded event time is removed from study-scope calculations for included uptime, utilization, projected production, and estimated production loss. Stopping the study also stops any active downtime event.
  • Add Manual Row lets you enter or correct an event manually.
  • Copy Selected Columns copies only the checked columns below into an Excel-ready paste format.
  • Copy Column Selection controls what gets copied; it does not hide or delete data from the log.
  • Downtime Code options come from the Reason Code Setup section below the event log.
  • The Start/Stop Downtime bars above and below the table mirror the main capture button and span the full table width for faster logging while entering notes.
  • Downtime cannot be started unless the study timer is running. Press Start Study first so downtime is captured inside observed time.
  • Manual Entry view hides timer controls and timestamp columns so the table can be filled from handwritten studies, spreadsheets, or operator notes.
  • Collapse shows the first and most recent event while keeping the full data available in exports.
Manual Entry: Enter the total study duration manually, then add rows using event duration, category, reason code, and notes. Timer buttons and timestamp columns are hidden in this view so the sheet works like a clean manual worksheet.

Downtime Code Setup

Reason Codes
Define downtime codes here before or during data collection. Use short abbreviations such as JAM, WAIT, QA, or MAT. These codes become selectable in the Event Log and are used to build the Pareto summary.
  • Reason Code Template is populated from compatible JSON templates found under 90_TEMPLATES in the connected Study Repository. Templates are no longer baked into this HTML.
  • Category / Group is the broad downtime area shown first in the Event Log.
  • Cause Code is the specific reason selected after a category is chosen. Each cause code must be unique.
  • Code description explains what the reason code means for anyone reviewing the data later.
  • Include in Summary controls whether a code/tag is included in downtime calculations, the Pareto summary, and the executive report. Raw events and exports still keep the original code.
  • Collapse shows the first and most recent code while retaining all definitions for exports and event dropdowns.
  • Specialty code-file import/export is intentionally kept in the hidden template-maintenance workspace so normal operators use controlled repository templates.
Connect the Study Repository to load templates from 90_TEMPLATES.
